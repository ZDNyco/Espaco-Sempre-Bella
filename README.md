
# Site-Espaço Sempre Bella

Site enfocado em mostrar o trabalho da equipe do salão e facilitar o agendamento.

Funcionalidades:
  *  Responsive design - Toda a pagina esta feita em 3 tipos de tamanho de tela, Celular, Tablets e Computador.
  *  Smart Nav - a aba de navegação se oculta ao descer na pagina, para melhor responsividad deixei um botão de menu.
  *  Botão menu - Abre a navegação, pode ser clicado com o mouse e o tab + enter, também tem a propriedade "hover".
  *  Menú Hamburger - Em telas pequenas a aba de navegação é trocada pelo menú hamburguer para melhor navegação.
  *  Identificação de sessão - Cada sessão esta identificada para possiveis melhorias/mudanças futuras.
  *  Serviços - Cada serviço e clicavel e apresenta por encima o que pode ser feito, o botão leva o usuário para agendamento.
  *  Portfólio - os botões mudam a ordem segundo o desejado e amostram só o esolhido.
  *  Formulário - Forms pronto para mandar os dados pelo whatsapp.
  *  Footer - Botões das redes sociais funcionais, e botão de WhatsApp com mensagem básica.

Melhorias:
  *  Erros ortográficos - Deixado para antes do lançamento.
  *  Botão menu - Melhora no design.
  *  Seções - Possível modificação ou melhoria das seções segundo pedido do cliente.
  *  Portfólio - Adição de fotos reais.
  *  Formulário - Troca do número de contato, modificação da mensagem de WhatsApp para melhor leitura.
  *  Footer - Modificação do link para adicionar o correto para cada botão.
  *  Mudanças que o cliente pedir.
